# YKurdo Remote — listing information, version 1.2.1

**Name:** YKurdo Remote

**One-liner:** Connect your MCP assistant to your Windows device with the 31 Personal tools, approved folders and local owner consent.

**Description:** YKurdo Remote has separate Personal (noncommercial) and Commercial Windows applications. Commercial 1.2.1 supports all 31 canonical Personal tool names, using the same engine for files, PDF, search and process sessions. Its account/device-management tools use the authenticated service.

Users choose approved folders and tool permissions on their device. Commercial Home offers Read Only, Ask and Full Auto. Ask requests native consent per device tool; locally selected Full Auto skips per-tool prompts while enforcing all permissions and server checks. Restart/logout restores Read Only. Shutdown requires separate consent and process tools require a locally opened execution window. The model cannot grant itself a folder or change protected security configuration. Account, device and lease checks are enforced on the server, including permission revocation before execution and result delivery.

The Personal application additionally has folder/whole-drive switches and a 15-minute execution-window panel. Product settings and installer identities remain separate. Commercial customers require a valid paid subscription or metered trial. Permanent Owner access is assigned by the service operator, separately from payment status.

**Requirements:** Windows x64, the matching updated application, a configured and connected device, and an MCP client that supports the connector. Commercial also requires a verified YKurdo account and active entitlement.
